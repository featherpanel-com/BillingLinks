# BillingLinks

Let users earn credits by completing monetized links (Links4Rewards). Integrates with **Billing Core** to credit users after verified link completions.


## Features

- **User-facing**
  - **Earn Credits → Link 4 Rewards** (`/earn/link4rewards`)
  - Browse enabled link providers
  - Start a link session, complete it, earn credits
  - View link completion history

- **Admin**
  - **Fremium Earn Credits → Link 4 Rewards**
  - Enable/disable Links4Rewards globally
  - Per-provider configuration: **Linkvertise**, **ShareUs**, **LinkPays**, **GyaniLinks**
  - Per provider: API key/user ID, credits per link, daily limit, min completion time, expiry, cooldown
  - View all generated links / completion log
